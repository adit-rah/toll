# api

One Cloudflare Worker: the JSON API under `/v1`, invite links (`/i/:code`), the Apple app-site-association file, and the legal pages (`public/`). Spec §11.2.

## Entry points
- `src/index.ts` — fetch, scheduled (cron) and queue handlers, wrapped by Sentry.
- `src/app.ts` — mounts every feature router. `src/features/<name>/routes.ts` per feature.
- `src/config.ts` — every tunable (spec §14), merged with KV `config:v1`. `src/copy.ts` — push and email text.

## Invariants
- Request and response shapes are Zod schemas in each feature's `contract.ts`; the iOS `TollData/API` models mirror them.
- Writes accept `Idempotency-Key`; event ingest is `ON CONFLICT(event_id) DO NOTHING`.
- Another person's data is only read through `src/domain/visibility.ts`.
- Server time (`received_at`) orders events; device time and offset are kept for display.
- Migrations in `migrations/` are generated by drizzle-kit and additive only.

## Develop
`npm ci && npm run check`. Local dev: `npm run db:migrate:local && npm run dev`. APNs does not work under `wrangler dev` (no HTTP/2); test pushes on the preview Worker.

## Remote config (E11.50)
`GET /v1/config?v=<app version>` (public) returns `src/config.ts` defaults merged with KV key `config:v1`: `{ "overrides": {…}, "byVersion": { "1.1": {…} } }`, deep-merged in that order. Cached 5 min at the edge and in the app (`serverConfig.configCacheSeconds`). Change it with `npx wrangler kv key put --binding CONFIG config:v1 '<json>' --remote`; a malformed document is ignored.

## First deploy (founders)
See `docs/deploy.md` for the full command list: create the D1 databases, KV namespace, R2 bucket and queue, paste their ids into `wrangler.jsonc`, set secrets, seed schools, then turn on CI deploys with the `DEPLOY_ENABLED` repository variable.

## Schools
`npm run schools:refresh` rewrites `seed/schools.sql` from the Hipo list (CA/US/GB). School ids are a stable hash of country and name, so memberships survive a refresh.
