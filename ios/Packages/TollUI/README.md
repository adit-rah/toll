# TollUI

Design tokens and components from `docs/toll-design.md` §2–§3: colours, type, `StatusGlyph`, `HeroStat`, `FriendRow`, `PinnedRow`, `WeekStrip`, `WhenChips`, buttons, `Avatar`, chart cards. Views only; no services.

Invariants
- Colours come from tokens with light and dark values; one accent on screen.
- Numbers use monospaced digits. Motion values come from `Motion` (design §2.5) and respect Reduce Motion.
